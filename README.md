## English Summary

**Subaka** is an open-source, full-featured subtitle editor and audiovisual localization workstation designed for translators, editors, voiceover artists, and content creators focusing on the Belarusian language. 

### Key Highlights:
- **Comprehensive Belarusian NLP Stack:** Built-in offline GrammarDB database (3.98M inflected word forms), BelG2P phonetics and stress mark placement, Hunspell-BE spellchecking, PravilnaBy orthographic rule validation, and native integration with Verbum.by dictionaries.
- **Full Subtitle Formats Support:** SubRip (`.srt`) and Advanced SubStation Alpha (`.ass`) with rich text styling, actor/role management.
- **Rich Media & Audio Engine:** Native playback of `.mp4`, `.webm`, `.mov`, and `.mkv` (x264/HEVC) and real-time audio extraction powered by native FFmpeg sidecars and WebAssembly.
- **AI-Assisted Capabilities:** Context-aware subtitle translation and batch proofreading via Gemini API, phonetic school transcription converter for voice actors, and Belarusian text-to-speech synthesis (Corpus.by "Ales" voice & Edge TTS & AI).
- **Cross-Platform:** Runs seamlessly right in modern web browsers or as high-performance desktop native binaries for Windows, macOS, and Linux (powered by Tauri v2 and Rust).

## Пра праект

**«Субака»** створаны для таго, каб зрабіць працэс стварэння, рэдагавання і беларусізацыі відэакантэнту хуткім, зручным і дакладным. 

Пры лакалізацыі на беларускую мову аўтары часта сутыкаюцца з тым, што інструментаў патрэбна шмат: 
адзін інструмент патрэбны для для канвертацыі відэа;
іншы, каб дастаць субцітры з відэа;
трэці -  гэта асобны рэдактар субцітраў, які можа быць не з тымі функцыямі, якія хацелася б;
і дзясятак ўкладак браўзера - для слоўнікаў, граматыкі і націскаў, файл для гласарыя, праверка арфаэпіі для літаратурнага агучвання.

«Субака» спалучае ўсе неабходныя інструменты ў адным: ад зручнага плэера да 4-мільённай граматычнай базы, школьнай фанетычнай транскрыпцыі і нават сінтэзу маўлення.

## Асноўныя магчымасці

### 🎬 Рэдагаванне і таймінг
* **Фарматы субцітраў:**
  * `.srt` (SubRip Subtitles) — стандарт для большасці плэераў і стрымінгавых платформаў (з падтрымкай фарматавання).
  * `.ass` (Advanced SubStation Alpha) — для размеркавання рэплік па ролях і персанажах.
* **Падтрымка медыяфарматаў (Відэа):**
  * `.mp4` (кодэкі H.264 / AAC) — поўная падтрымка ва ўсіх асяроддзях.
  * `.webm` (кодэкі VP8, VP9, AV1).
  * `.mov` (кодэк H.264).
  * `.mkv` (кантэйнер Matroska):
    * Кодэк `x264` / `H.264` (Chrome, Edge, Safari, Tauri).
    * Кодэк `x265` / `HEVC` (падтрымліваецца ў Chrome 107+, Safari і натыўнай зборцы).
* **Падтрымка аўдыя:**
  * Аўтаматычная апрацоўка любых распаўсюджаных фарматаў: `.mp3`, `.wav`, `.aac`, `.m4a`, `.ogg`, `.flac`, `.ac3`, `.eac3`.
  * Выбар патрэбнай аўдыядарожкі проста ў плэеры.
* **Эрганоміка таймлайну:**
  * Зручны плэер з пераменнай гучнасцю, хуткасцю, адлюстраваннем роляў.
  * Віртуалізаваны спіс радкоў: хуткая праца з тысячамі субцітраў адначасова і арыгінала і перакладу, ці 2-х версій перакладу для рэдактуры.
  * Кантроль хуткасці чытання: аўтаматычны разлік знакаў у секунду (**CPS**) з каляровай індыкацыяй перавышэння лімітаў.
  * Групавы зрух таймінгу (time-shift) для ўсіх ці асобнага субцітра.
  * Магчымасць адфільтраваць толькі субцітры з памылкамі, пошук і замена па субцітрах.
  * І зручныя дробязі, без якіх часам праца з субцітрамі дужа раздражняе.
* **Гласарый праекта:**
  * Падтрымка ўласнага слоўніка тэрмінаў, імёнаў і назваў. Імпарт і экспарт у фарматах `.csv` і `.txt`.

---

### 🇧🇾 Беларускі моўны модуль
* **Убудаваная граматычная база (GrammarDB):**
  * Інтэграваная аўтаномная база SQLite, якая змяшчае **3.98 млн словаформаў** (GrammarDB v0.4.3).
  * Праверка існавання і парадыгмы слова без неабходнасці інтэрнэт-злучэння.
* **Праверка арфаграфіі і правілаў:**
  * Праверка правапісу па слоўніках **Hunspell-BE** (RZR team / BNKorpus.info).
  * Аналіз правілаў беларускага правапісу на базе алгарытмаў **PravilnaBy**.
* **Арфаэпічны модуль:**
  * Канвертацыя ў **школьную фанетычную транскрыпцыю** (для чыткі дыктарам, дубляжу ці вывучэння мовы) на аснове баз Беларускага N-корпуса (bnkorpus.info) і рухавіка **BelG2P**.
* **Пошук па слоўніках Verbum.by:**
  * Хуткі доступ да аўтарытэтных тлумачальных, перакладных і гістарычных слоўнікаў (ТСБЛМ, ТСБМ, ЭСБМ, БРС і інш.) без выхаду з рэдактара.
  * Лакальны кэш для стабільнай працы пры абмежаваным доступе да сеткі.

---

### ⚡ Апрацоўка відэа і FFmpeg
* **Натыўны FFmpeg sidecar (Tauri):** дэсктопныя версіі выкарыстоўваюць убудаваны бінарнік FFmpeg для канвертацыі аўдыядарожак з відэафайлаў.
* **WebAssembly (FFmpeg.wasm):** аўтаномная канвертацыя аўдыядарожак (якія не прайграюцца ў браўзеры) без адпраўкі відэа на серверы.

---

### 🤖 Інтэлектуальныя інструменты
* **AI-пераклад і вычытка (Gemini API):**
  * Кантэкстны пераклад рэплік з іншых моў на літаратурную беларускую мову.
  * Пакетныя парады AI па стылістыцы, сінтаксісу і памылках (пераправярайце AI, пераклад усё ж робіць чалавек).
* **Сінтэз маўлення (TTS / Агучка):**
  * Падтрымка беларускага сінтэзатара ад **Corpus.by** (галасавы рухавік «Алесь»).
  * Падтрымка **Edge TTS** ці AI агучкі, ці загрузка сваёй гукавай дарожкі да відэа.

## Тыповыя сцэнарыі выкарыстання (Quick Start)

### Сцэнар 1: Стварэнне і пераклад субцітраў з нуля
1. Імпартуйце відэа- або аўдыяфайл у праграму.
2. Імпартуйце зыходныя субцітры ("арыгінал") ў фармаце `.srt` ці `.ass` (або стварыце субцітры).
3. Пры неабходнасці скарыстайцеся AI-перакладам на беларускую мову, можна імпартаваць праектны гласарый (`.csv`/`.txt`) ці напаўняць яго ў працэсе працы.
4. Экспартуйце гатовы файл ("пераклад") `.srt` або `.ass`.

### Сцэнар 2: Карэкцыя і вычытка гатовага перакладу
1. Імпартуйце зыходныя субцітры арыгінал і пераклад.
2. Звярніце ўвагу на аўтаматычную падсветку памылак правапісу ў перакладзе.
3. На слова можна паставіць курсор ці вылучыць яго для праверкі марфалогіі па граматычнай базе **GrammarDB** або адкрыць пошук слова ў **Verbum.by**.
4. Праверце значэнні CPS (знакаў у секунду), каб пераканацца, што глядач паспее прачытаць тэкст на экране.

### Сцэнар 3: Падрыхтоўка матэрыялаў для агучкі (дубляжу)
1. Імпартуйце зыходныя субцітры ў арыгінал.
2. Перавядзіце рэплікі ў **школьную транскрыпцыю** (з'явяцца ў полі "пераклад").

### Сцэнар 4: Размеркаванне роляў і экспарт па персанажах
1. Імпартуйце зыходныя субцітры ў пераклад.
2. Задайце кожнай рэпліцы адпаведнага персанажа (акцёра).
3. Экспартуйце агульны файл з ролямі `.ass` або асобныя субцітры па кожнай ролі `.srt`.

## Зборка з зыходнага коду

Для распрацоўкі і лакальнай зборкі вам спатрэбяцца:
* **Node.js** версіі 20 або вышэй
* **Rust** і **Cargo** (для дэсктопнай версіі Tauri)

### Крокі зборкі:

```bash
# 1. Кланіраванне рэпазітарыя
git clone https://github.com/your-username/subaka.git
cd subaka

# 2. Усталёўка npm-залежнасцей
npm install

# 3. Запуск у рэжыме вэб-распрацоўкі (Vite)
npm run dev

# 4. Запуск у дэсктопным рэжыме (Tauri Dev)
npm run tauri:dev

# 5. Поўная зборка інсталятараў для бягучай аперацыйнай сістэмы
npm run tauri:build
```

## Шчыры дзякуй

Праект **«Субака»** стаіць на плячах выдатных адкрытых ініцыятыў беларускіх лінгвістаў і супольнасці. Глыбокая ўдзячнасць аўтарам і даследчыкам:

1. 🏛️ **[GrammarDB](https://github.com/Belarus/GrammarDB)** (`v0.4.3`) — граматычная база беларускай мовы (3.98M словаформаў у фармаце SQLite).
2. 🗣️ **[BelG2P](https://github.com/Belarus/BelG2P)** — алгарытмы фанетычнай транскрыпцыі, правілы і базы беларускага націску.
3. ✍️ **[PravilnaBy](https://github.com/alroniks/pravilnaby)** (`v0.1.0`) — алгарытмы і правілы беларускага правапісу.
4. 🔍 **[Hunspell-BE](https://spell.by-reservation.com/)** (`v0.5.2`) — афіцыйны пакет праверкі арфаграфіі (RZR team / BNKorpus.info).
5. 📊 **[Беларускі N-корпус (bnkorpus.info)](https://bnkorpus.info)** — корпус беларускай мовы, статыстыка частатнасці і базы націскаў.
6. 📖 **[Verbum.by](https://verbum.by)** — адкрыты корпус лічбавых слоўнікаў беларускай мовы (ТСБЛМ, ТСБМ, ЭСБМ, БРС і інш.).
7. 🎙️ **[Corpus.by](https://corpus.by/TextToSpeechBelarusianPy/?lang=be)** — API сінтэзу маўлення беларускай мовы (голас «Алесь»).

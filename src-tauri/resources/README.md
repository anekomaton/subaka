# SUBaka Desktop Resources
This directory contains offline SQLite dictionaries, models, executables, and DLLs bundled with SUBaka for Windows:

### Dictionaries
- `verbum_offline.sqlite3`
- `grammardb.sqlite3`

### Speech Recognition (Whisper.cpp)
- `whisper.exe` (CPU standard build)
- `whisper-cuda.exe` (NVIDIA CUDA / cuBLAS GPU build)
- `ggml-small.bin` (GGML offline model)

### Runtime Dynamic Libraries (DLLs)
- `whisper.dll`
- `ggml.dll`, `ggml-cpu.dll`, `ggml-cuda.dll`, `ggml-base.dll`
- `cublas64_*.dll`, `cublasLt64_*.dll`, `cudart64_*.dll`
- `nvrtc64_*.dll`, `nvrtc-builtins64_*.dll`
- `SDL2.dll`

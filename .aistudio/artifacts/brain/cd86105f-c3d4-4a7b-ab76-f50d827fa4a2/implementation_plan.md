# План стварэння README.md для рэпазітарыя «Субака» на GitHub

## Мэта
Падрыхтаваць якаснае, зразумелае і падрабязнае апісанне праекта **«Субака»** (Subaka) для размяшчэння ў корані рэпазітарыя (`README.md`), арыентаванае на карыстальнікаў (перакладчыкаў, рэдактараў, стваральнікаў відэа, субтытроўшчыкаў і лакалізатараў беларускамоўнага кантэнту).

---

## 1. Загаловак, слоган і бэйджы (Badges)

- Інфармацыйныя бэйджы:

  - Статусы зборкі GitHub Actions (CI/CD: Web, Windows, macOS, Linux)

  - Ліцэнзія: `Apache-2.0` / Open Source

---

## 2. English Brief Summary (Кароткі ўводны блок для замежных гасцей)
- **What is Subaka?** Сучасны спецыялізаваны рэдактар субцітраў і аўдыя-візуальны інструмент, створаны для перакладу, рэдагавання, карэкцыі правапісу і агучкі медыякантэнту.
- **Key Highlights:**
  - Full Belarusian NLP stack: GrammarDB (3.98M inflected word forms), BelG2P phonetics & stress, Hunspell-BE spellchecking, PravilnaBy orthography rules, and offline/online Verbum.by dictionaries.
  - Subtitle formats: SubRip (`.srt`) and Advanced SubStation Alpha (`.ass`) with role/actor support.
  - Audio & Video support: MP4, WebM, MOV, MKV, MP3, WAV, FLAC, AAC, etc., with native FFmpeg processing.
  - AI translation & proofreading (Gemini API), phonetic school transcription, and speech synthesis (Corpus.by "Ales" & Edge TTS).
  - Cross-platform: Web application & native desktop apps (Windows, macOS, Linux) powered by Tauri & Rust.

## 3. Пра праект (Агляд па-беларуску)
- Для каго і навошта створана «Субака»:
  - Спрашчэнне і паскарэнне беларусізацыі сусветнага і лакальнага відэакантэнту.
  - Зручны рэдактар субцітраў з жывой гукавой хваляй, адсочваннем хуткасці чытання (CPS) і таймінгу.
  - Унікальная інтэграцыя аўтарытэтных беларускіх моўных баз у адным акне (больш не трэба адкрываць дзясяткі ўкладак слоўнікаў паралельна з рэдактарам).

## 4. Асноўныя магчымасці (Фічы)

### 🎬 Рэдагаванне і таймінг
- **Падтрымка фарматаў субцітраў:**
  - `.srt` (SubRip Subtitles) — класічны стандарт.
  - `.ass` (Advanced SubStation Alpha) — стылі, колеры і размеркаванне па ролях/персанажах.
- **Падтрымка медыяфарматаў (Відэа):**
  - Ва ўсіх сучасных браўзерах: `.mp4` (кодэк H.264 / AAC), `.webm` (кодэкі VP8/VP9/AV1), `.mov` (H.264).
  - Кантэйнер `.mkv`:
    - Кодэк `x264` / `H.264` (Chrome, Edge, Safari).
    - Кодэк `x265` / `HEVC` (падтрымліваецца ў Chrome 107+ і Safari).
- **Падтрымка аўдыя:**
  - Аўтаматычная апрацоўка любых распаўсюджаных фарматаў праз убудаваны канвертар: `.mp3`, `.wav`, `.aac`, `.m4a`, `.ogg`, `.flac`, `.ac3`, `.eac3` і інш.
- **Гласарый праекта:**
  - Імпарт і экспарт слоўнікаў тэрмінаў у фарматах `.csv` і `.txt`.
- **Эрганоміка таймлайну:**
  - Візуалізацыя гукавой хвалі (waveform) з інтэрактыўным скролам і маштабаваннем.
  - Віртуалізаваны спіс радкоў (хуткая праца нават з тысячамі субцітраў).
  - Кантроль хуткасці чытання: індыкацыя знакаў у секунду (CPS) і слоў у хвіліну (WPM).
  - Зрух таймінгу ўсіх субцітраў або асобных фрагментаў.

### 🇧🇾 Беларускі моўны модуль
- **Убудаваная граматычная база (GrammarDB):**
  - Лакальная база дадзеных SQLite з 3.98 млн словаформаў (GrammarDB v0.4.3).
  - Імгненны марфалагічны аналіз і праверка існавання формы слова без падключэння да інтэрнэту.
- **Праверка арфаграфіі і правілаў:**
  - Модуль праверкі правапісу на базе Hunspell-BE (RZR team / BNKorpus.info).
  - Праверка правілаў беларускага правапісу па алгарытмах PravilnaBy.
- **Арфаэпічны канвертар і націскі:**
  - Аўтаматычная расстаноўка націскаў у словах па базе Беларускага N-корпуса (bnkorpus.info) і BelG2P.
  - Генерацыя **школьнай фанетычнай транскрыпцыі** (напрыклад, для чыткі дыктарам ці акторам агучкі).
- **Інтэграцыя са слоўнікамі Verbum.by:**
  - Пошук па тлумачальных, перакладных і этымалагічных слоўніках (ТСБЛМ, ТСБМ, ЭСБМ, БРС і інш.) наўпрост з інтэрфейсу праграмы.
  - Лакальны аўтаномны кэш на выпадак недаступнасці інтэрнэту.

### ⚡ Апрацоўка відэа і FFmpeg
- Хуткая натыўная апрацоўка праз убудаваны бінарнік FFmpeg sidecar у дэсктопнай версіі (Tauri / Rust).
- WebAssembly (FFmpeg.wasm) і серверная аптымізацыя для браўзернай версіі.
- Імгненнае выманне аўдыядарожкі з відэафайлаў любога аб'ёму.

### 🤖 Інтэлектуальныя інструменты
- **Пераклад і вычытка праз штучны інтэлект (Gemini API):**
  - Пакетны пераклад рэплік з іншых моў на беларускую.
  - Інтэлектуальная вычытка перакладу з захаваннем кантэксту і стылістыкі.
- **Сінтэз маўлення (TTS / Агучка):**
  - Інтэграцыя з сэрвісам Corpus.by (натуральны беларускі голас «Алесь»).
  - Падтрымка галасоў Edge TTS для хуткага чарнавога праслухоўвання і экспарту агучкі.

## 6. Тыповыя сцэнарыі выкарыстання (Quick Start)

### Сцэнар 1: Стварэнне і пераклад субцітраў
1. Перацягніце відэа- ці аўдыяфайл у акно праграмы (аўдыядарожка і гукавая хваля згенеруюцца аўтаматычна).
2. Імпартуйце арыгінальныя субцітры (`.srt` ці `.ass`) альбо пачніце ствараць новыя рэплікі па гукавой хвалі.
3. Скарыстайцеся функцыяй перакладу праз Gemini AI і падключыце свой гласарый (`.csv`/`.txt`) для дакладных тэрмінаў.

### Сцэнар 2: Праверка і карэкцыя гатовага перакладу
1. Загрузіце гатовыя субцітры ў рэдактар.
2. Праверце тэкст убудаванымі інструментамі арфаграфіі:
   - Падсветка памылак праз Hunspell-BE і PravilnaBy.
   - Праверка слоў і словаформаў праз 4-мільённую базу GrammarDB.
   - Хуткі пошук значэнняў і ідыём праз слоўнікі Verbum.by у суседнім акенцы.

### Сцэнар 3: Генерацыя транскрыпцыі і націскаў для беларускамоўнай агучкі
1. Вылучыце патрэбныя рэплікі ці ўвесь спіс субцітраў.
2. Запусціце аўтаматычную расстаноўку націскаў і канвертацыю ў школьную транскрыпцыю.
3. Праслухайце або згенеруйце чарнавую аўдыядарожку праз голас «Алесь» (Corpus.by) ці Edge TTS для актораў дубляжу.

### Сцэнар 4: Размеркаванне роляў і экспарт субцітраў
1. Прызначце кожнай рэпліцы адпаведнага персанажа/актора.
2. Наладзьце стылі і колеры па ролях у фармаце ASS.
3. Экспартуйце выніковы файл у `.ass` з разметкай альбо адфільтруйце і захавайце асобныя рэплікі для кожнага актора.

## 7. Зборка з зыходнага коду (Для распрацоўшчыкаў)
- **Патрабаванні:**
  - Node.js 20+ і npm.
  - Rust і Cargo (для зборкі дэсктопнай версіі праз Tauri v2).
- **Каманды:**
  ```bash
  # Усталёўка залежнасцей
  npm install

  # Запуск у рэжыме вэб-распрацоўкі
  npm run dev

  # Запуск лакальнай дэсктопнай версіі (Tauri)
  npm run tauri:dev

  # Зборка дыстрыбутываў пад бягучую платформу
  npm run tauri:build
  ```

## 8. Шчыры дзякуй (Выкарыстаныя крыніцы, версіі і спасылкі)
Праект «Субака» выказвае глыбокую ўдзячнасць супольнасці і аўтарам адкрытых беларускіх моўных ініцыятыў:

1. [GrammarDB](https://github.com/Belarus/GrammarDB) (`v0.4.3`) — граматычная база беларускай мовы (3.98M словаформаў, SQLite).
2. [BelG2P](https://github.com/Belarus/BelG2P) — рухавік націскаў, фанетычны канвертар і правілы беларускага націску.
3. [PravilnaBy](https://github.com/alroniks/pravilnaby) (`v0.1.0`) — правілы і алгарытмы беларускага правапісу.
4. [Hunspell-BE](https://spell.by-reservation.com/) (`v0.5.2`) — пакет праверкі арфаграфіі (RZR team / BNKorpus.info).
5. [БНКорпус (bnkorpus.info)](https://bnkorpus.info) — Беларускі N-корпус (статыстыка, частата і базы націскаў).
6. [Verbum.by](https://verbum.by) — адкрыты корпус слоўнікаў беларускай мовы (ТСБЛМ, ТСБМ, ЭСБМ, БРС і інш.).
7. [Corpus.by](https://corpus.by/TextToSpeechBelarusianPy/?lang=be) — API сіннтэзатара маўлення (беларускі голас «Алесь»).
